### O.R.B.I.T.

**Optical Ranging, Bearing & Identification Telemetry**

A research project working toward an inexpensive modular perception sensor capable of turning camera data into structured target information.

The current prototype combines a calibrated stereo camera rig with **YOLO detection, epipolar matching, triangulation, persistent track IDs, and Kalman-smoothed depth estimation**.

`cameras → detection → matching → ranging → tracking → telemetry`

[View project →](https://github.com/jonahchang207/O.R.B.I.T)

---

### Odyssey

A reusable **VEX V5 odometry and autonomous motion framework** built on PROS.

It provides field-relative position tracking alongside PID motion, boomerang-style move-to-pose control, pure pursuit path following, and an experimental Monte Carlo localization layer using distance sensors.

`odometry → localization → path planning → motion`

[View project →](https://github.com/jonahchang207/odyssey) · [Documentation →](https://jonahchang207.github.io/odyssey/)

---

### SourceSight

A Linux-native **C++20 real-time visualization system** built around a custom Dear ImGui interface.

The project includes asynchronous geometry loading, spatial culling, camera-plane and screen-edge clipping, map visualization, configurable overlays, and persistent profiles.

`process data → geometry → visualization → interaction`

[View project →](https://github.com/jonahchang207/sourcesight-linux)
