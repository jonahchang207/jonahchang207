### 🧭 [Odyssey](https://github.com/jonahchang207/odyssey)

A reusable **odometry and motion-control framework** for VEX V5 robots using PROS.

Designed to provide a strong foundation for autonomous navigation, position tracking, and precise robot movement.

### 🦾 [IRIS](https://github.com/jonahchang207/IRIS-Progect)

A vision-guided **6-degree-of-freedom robotic arm** combining YOLOv11 object detection, analytical inverse kinematics, and Teensy-based hardware control.

Built to explore intelligent manipulation and real-world robotic perception.
